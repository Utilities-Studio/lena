# `@lena-inc/vault`

Encrypted local-vault lifecycle, transaction, and recovery contracts for Lena.

```sh
bun add @lena-inc/vault
```

This package is pre-1.0. Read the [Lena overview](https://github.com/utilities-studio/lena#readme)
and [implementation status](https://github.com/utilities-studio/lena/blob/main/docs/STATUS.md)
before production adoption.
